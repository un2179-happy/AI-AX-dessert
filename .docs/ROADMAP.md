## 2. 개발 방향 (우선순위 순)

1. **공개 배포와 실사용 확인 먼저**: 브라우저·모바일에서 실제로 어떻게 보이는지 확인하고 피드백을 받는다. 아직 눈으로 확인하지 못한 부분이 있다 (유럽 라벨 겹침 등).
2. **재미와 재방문**: 결과 공유, 취향 기록, "왜 이 결과인가" 설명을 넣어 한 번 하고 끝나는 게임이 되지 않게 한다.
3. **추천 품질**: 디저트와 질문을 늘리고, 답변 신뢰도와 속성 중요도를 반영해 점수 방식을 개선한다.
4. **유지보수성**: 데이터를 코드에서 분리해 디저트·질문을 쉽게 추가하게 한다.
