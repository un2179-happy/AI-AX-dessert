# 디저트 취향 스무고개 - 테스트 계획서

대상: [index.html](../index.html) (단일 파일, 클라이언트 사이드)
기준 문서: [PRD.md](PRD.md)

## 1. 목적과 범위

PRD의 핵심 기능과 성공지표가 구현에서 충족되는지 검증한다.

| 구분 | 범위 |
|------|------|
| 포함 | 질문 선택/종료 로직, 점수 계산, 결과 화면, 세계지도·레이더·막대 시각화, 반응형, 접근성, 브라우저 호환성 |
| 제외 | 백엔드(없음), 저장/공유 기능(Phase 3), 다국어 |

## 2. 테스트 환경

- 브라우저: Chrome, Edge, Firefox, Safari (각 최신 버전)
- 기기: 데스크톱(1280px 이상), 태블릿(768px), 모바일(360px)
- 실행: 파일을 직접 열기 (file://), 네트워크 차단 상태 포함
- 도구: 브라우저 개발자 도구(콘솔/Lighthouse), Node.js(로직 시뮬레이션)

## 3. 기능 테스트 케이스

### 3.1 흐름

| ID | 시나리오 | 기대 결과 | 우선순위 |
|----|----------|-----------|----------|
| F-01 | 페이지 최초 로드 | 시작 화면만 표시, 콘솔 오류 없음 | 높음 |
| F-02 | 시작하기 클릭 | 질문 화면, "질문 1 / 20", 진행바 0% | 높음 |
| F-03 | YES/NO 클릭 | 다음 질문으로 이동, 카운트·진행바 증가 | 높음 |
| F-04 | 키보드 Y / N | 버튼 클릭과 동일하게 동작 | 중간 |
| F-05 | 질문 화면 외에서 Y / N 입력 | 아무 동작 없음 | 중간 |
| F-06 | "처음으로" 클릭 | 시작 화면 복귀, 다시 시작 시 점수·질문 기록 초기화 | 높음 |
| F-07 | 결과 화면 "다시 하기" | 새 게임 시작, 이전 결과 잔존 없음 | 높음 |
| F-08 | 답변을 빠르게 연타 | 질문이 건너뛰어지거나 중복 처리되지 않음 | 높음 |

### 3.2 질문·종료 로직

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| L-01 | 한 게임에서 같은 질문이 2회 나오는지 | 나오지 않음 |
| L-02 | 질문 수 상한 | 20개를 넘지 않음 (현재 질문 풀은 17개이므로 최대 17개) |
| L-03 | 선두와 2위 점수 차 3 이상, 6문항 이상 응답 | 즉시 결과 화면 |
| L-04 | 6문항 미만에서 점수 차가 3 이상 | 종료하지 않고 계속 진행 |
| L-05 | 모든 질문이 후보를 나누지 못하는 상태 | 결과 화면으로 정상 이동 (멈춤/오류 없음) |
| L-06 | 같은 답변을 반복해 여러 게임 진행 | 질문 순서와 문구가 게임마다 달라짐 (가중 랜덤 선택 + 문구 변형 3종). 단, 같은 시드로는 재현됨 |

### 3.3 점수·결과

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| S-01 | 일치 답변 | 해당 디저트 +1, 불일치 -1 |
| S-02 | 모든 질문에 YES | 결과가 오류 없이 표시되고 일치도 0~100% 범위 |
| S-03 | 모든 질문에 NO | 위와 동일 |
| S-04 | "차갑다/크리미/초콜릿 = YES" 등 일관된 답변 | 상위 추천이 해당 속성의 디저트 (예: 젤라또, 티라미수 계열) |
| S-05 | 일치도 % 표기 | 0~100 정수, 1위가 가장 높거나 동률 |
| S-06 | 지역 점수 | 해당 지역 디저트 중 최고 일치도와 같음 |
| S-07 | 동점 디저트 | 오류 없이 순위가 정해짐 (표시 순서 일관) |

### 3.4 시각화

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| V-01 | 결과 화면 지도 | 대륙 도형 + 9개 지역 핀 + 동심원 표시 |
| V-02 | 1위 지역 | 📍 표시, 핀이 더 크고 진한 색 |
| V-03 | 일치도가 높은 지역 vs 낮은 지역 | 동심원 크기·진하기 차이가 보임 |
| V-04 | 핀 호버 / 키보드 포커스 | 지역명·계보·디저트별 일치도 툴팁 표시, 벗어나면 사라짐 |
| V-05 | 유럽 지역(프랑스·이탈리아·오스트리아·스페인·튀르키예) | 라벨이 서로 겹쳐 읽기 어렵지 않음 |
| V-06 | 레이더 차트 | 8개 축, 상위 3개 디저트 가중 평균 반영, 값 0~1 |
| V-07 | 막대 그래프 | 상위 5개 지역, 내림차순, 막대 길이와 % 일치 |
| V-08 | 모든 지역 점수가 같은 경우 | 지도가 깨지지 않음 (NaN 없음) |

## 4. 비기능 테스트

| ID | 항목 | 기준 | 방법 |
|----|------|------|------|
| N-01 | 로딩 시간 | 1초 미만 | Lighthouse / Performance 탭 |
| N-02 | 지도 렌더링 | 500ms 미만 | `performance.now()`로 `drawMap` 측정 |
| N-03 | 오프라인 동작 | 네트워크 차단에도 정상 | 개발자 도구 Offline, 외부 요청 0건 확인 |
| N-04 | 콘솔 오류/경고 | 0건 | 전체 흐름 수행 후 확인 |
| N-05 | 반응형 | 360px에서 가로 스크롤 없음, 버튼 터치 가능 크기 | 기기 에뮬레이션 |
| N-06 | 접근성 | 키보드만으로 전체 흐름 가능, 포커스 표시, 색 외 정보(수치 라벨) 병행 | 수동 + Lighthouse Accessibility |
| N-07 | 색약 대응 | 단일 색상 계열 농도로 구분, 수치 라벨 병기 | 색약 시뮬레이션 |
| N-08 | 이모지 렌더링 | Windows/macOS/모바일에서 깨지지 않음 | 각 환경에서 확인 |
| N-09 | 브라우저 호환성 | 4개 브라우저에서 F, V 케이스 통과 | 테스트 매트릭스 |

## 5. 자동화 로직 검증 (Node 시뮬레이션)

가짜 DOM으로 `<script>`를 실행해 다음을 반복 검증한다.

1. 무작위 답변 1,000회: 예외 없이 결과 화면 도달
2. 모든 게임에서 질문 중복 없음, 질문 수 20 이하
3. 모든 일치도가 0~100 범위, NaN 없음
4. 고정 답변 시퀀스 → 고정 결과 (회귀 테스트)
5. 속성 일관 답변 시 기대 디저트가 Top 3 안에 포함되는지

(1회 실행 결과: 무작위 500회 실패 0건. 2~5번은 미실시)

## 6. 사용자 수용 테스트 (UAT)

대상: 5~10명. 지표는 PRD 9장 성공지표와 연결한다.

| 항목 | 목표 | 방법 |
|------|------|------|
| 추천 만족도 | 80% 이상 "내 취향과 비슷하다" | 결과 직후 1문항 설문 |
| 완료율 | 95% 이상 | 시작 대비 결과 도달 관찰 |
| 지도 이해도 | 80% 이상이 5초 안에 "내 취향 계보" 설명 가능 | 관찰 + 구두 질문 |
| 평균 소요시간 | 3~5분 | 스톱워치 |

## 7. 알려진 위험과 확인 사항

- 지도는 대륙을 거칠게 그린 도형이라 지리적 정확도가 낮음. 핀 위치가 대륙 안에 있는지 육안 확인 필요
- 질문 풀이 17개라 PRD의 "20문항" 보다 적음. 사용자에게 충분히 변별되는지 UAT에서 확인
- 후보 디저트가 20개뿐이라 편중된 답변에서는 같은 결과가 자주 나올 수 있음
- Safari에서 `mix-blend-mode`, SVG `paint-order` 렌더링 차이 가능성

## 8. 종료 기준

- 높음 우선순위 케이스 100% 통과, 중간 90% 이상 통과
- 치명적/주요 결함 0건
- 콘솔 오류 0건, 4개 브라우저 통과
- UAT 만족도 80% 이상
